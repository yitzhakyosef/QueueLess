# QueueLess - מספרת רמת גן

מערכת דמו לקביעת תורים במספרה, שנועדה למנוע בלאגן בתורים, כפילויות, שיחות טלפון מיותרות וניהול ידני ב-WhatsApp.

המערכת היא MVP לקורס Vibe Coding: פשוטה, עובדת, בעברית, RTL, עם חוויית משתמש שנראית כמו אתר אמיתי של מספרה.

## מה המערכת יודעת לעשות

- לקוח נרשם ומתחבר בצורה מסודרת.
- לקוח קובע תור עם שירות, תאריך, שעה ונייד כשדות חובה.
- לקוח רואה את “התורים שלי” ואת סטטוס התור שלו.
- שעה ננעלת מיד אחרי שליחת בקשה, גם כשהסטטוס עדיין `pending`.
- ביטול תור משחרר את השעה בחזרה.
- בעל העסק מאשר ומבטל תורים.
- בעל העסק חוסם טווחי תאריכים שבהם המספרה סגורה.
- בעל העסק רואה רשימת לקוחות, כמות תורים וחיפוש לפי שם או נייד.
- נתונים נשמרים ב-`localStorage` ושורדים רענון.
